Get started

Up and running in under a minute.

  1. Download and unzip. Put the folder anywhere, for example your Documents.
  2. Open {{EXE}}. If Windows SmartScreen appears, click More info, then Run anyway.
  3. Add games. Pick a console in Games and click Add files, or grab free games from Discover.
  4. Play. Click a game. Plug in a controller any time.

Questions

 

Is it free?

Yes. The app is free, and so are the homebrew games in Discover.

Why does PlayStation need a BIOS?

PlayStation games start from the console's own startup software. Dump it from your console and add it in Settings › BIOS files.

Where are my saves?

Next to each game: .sav for cartridge games and .mcd memory cards for PlayStation.

Windows says the app is unrecognised

New apps without a paid code-signing certificate show this warning. Click More info and then Run anyway.
